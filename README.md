# B2C Web App — OpenID Connect (.NET)

Fork of the [Microsoft Azure AD B2C sample](https://github.com/Azure-Samples/active-directory-b2c-dotnet-webapp-and-webapi) demonstrating OpenID Connect authentication with Azure AD B2C in an ASP.NET web application.

## What's Inside

- ASP.NET MVC web app configured for Azure AD B2C sign-up/sign-in
- OWIN middleware for OpenID Connect
- Token-based calls to a protected Web API
